# NOC Health Dashboard

A real-time Network Operations Center (NOC) dashboard built with Flask, SNMP, and Chart.js.

## Features
- **Secure Login**: Session-based authentication
- **Live Device Monitoring**: CPU & Memory usage from 3 network devices
- **Status Alerts**: Color-coded OK, WARNING, CRITICAL status
- **Bar Chart**: Current CPU & Memory usage comparison
- **Line Chart**: CPU Trend over last 10 runs
- **Auto Refresh**: Dashboard updates every 10 seconds
- **Data Logging**: Historical data stored in CSV

## Tech Stack
`Python` `Flask` `SNMP` `Chart.js` `HTML/CSS` `CSV`
